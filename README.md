# OrçaFlow — demonstração de fluxo de orçamentos

Criei esta interface para mostrar como uma empresa pode organizar pedidos de orçamento que normalmente chegam espalhados por mensagens, fotos e anotações.

A demonstração reúne um formulário de solicitação, um painel com exemplos de pedidos e uma visão das etapas de atendimento. Também é possível simular o envio de uma solicitação e pesquisar registros na tabela.

## Executar

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Tecnologias

HTML, CSS e JavaScript, sem frameworks.

## O que é demonstrativo

Este repositório contém apenas o frontend. Os pedidos exibidos são fictícios; não há backend, autenticação, banco de dados nem persistência das solicitações. O envio apenas atualiza a tabela exibida na página durante a sessão.

O objetivo é apresentar o fluxo e a interface, não simular um produto pronto para produção.
